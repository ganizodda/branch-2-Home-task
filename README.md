# StayEase — лендинг для бронирования отелей

Современная и адаптивная посадочная страница для сервиса бронирования отелей. Проект демонстрирует стильный интерфейс главной страницы платформы с поиском жилья, навигацией и формой бронирования.

## Предпросмотр

Страница включает:

- Адаптивное меню навигации
- Hero-секцию с описанием сервиса
- Форму поиска и бронирования
- Современный минималистичный дизайн
- Кнопки призыва к действию
- Блок с видео-просмотром

## Возможности

- 📱 Адаптивная верстка
- 🎨 Современный UI/UX дизайн
- 🏨 Интерфейс бронирования отелей
- 🔍 Поиск жилья
- ▶️ Просмотр видео
- 🧭 Навигационное меню
- 🔐 Кнопка входа
